# BUY LATER QUEST｜購物冷靜期

以 HTML、CSS 和原生 JavaScript 製作的遊戲化購物冷靜期網站。任務、決策和冒險經驗會保存在目前瀏覽器的 `localStorage`，不需要帳號或伺服器。

## 開始使用

直接用瀏覽器開啟 `index.html` 即可。選擇「接受新任務」，填入商品名稱、整數價格和 24 小時、3 天或 7 天冷靜期。任務到期後可決定購買、延長等待或放棄；等待期間也能提前放棄。購物紀錄及統計會自動更新。

## GitHub Pages 部署

1. 將 `index.html`、`style.css`、`script.js` 和本說明檔放在 GitHub 儲存庫根目錄。
2. 在儲存庫的 **Settings → Pages**，選擇 **Deploy from a branch**。
3. 選擇要部署的分支和 `/ (root)` 資料夾並儲存。
4. 等待 GitHub Pages 完成部署，再開啟設定頁提供的網址。

網站沒有建置步驟或伺服器端依賴。每個瀏覽器各自保存資料；清除網站資料會移除任務，目前尚未提供匯出、備份或跨裝置同步。

## 功能與規則

- 倒數依保存的截止時間計算，頁面每分鐘更新；重新開啟網站會重新判定到期狀態。
- 保住的預算只加總「已放棄」任務，每筆任務只計算一次。
- 每完成一次購買或放棄決定可獲得 20 EXP；累積 100 EXP 升一級。延長冷靜期不會取得 EXP。
- 任務圖鑑可依狀態篩選；冒險紀錄列出已完成決定，延長紀錄保存在該任務的歷程資料中。
- 成就會依任務和決策紀錄即時計算。
- 提醒只會在網站內顯示，不提供關閉頁面後的系統通知。

## 手動驗收清單

- 新增任務後重新整理頁面，確認任務仍在且倒數合理。
- 建立 24 小時任務可檢查顯示時間；到期時任務會出現在待評估狀態。
- 到期任務分別試用購買、延長和放棄，確認任務狀態、EXP 和預算統計更新。
- 對等待中的任務提前放棄，確認只計入一次保住的預算。
- 在手機寬度檢查任務、表單和底部導覽均可操作，頁面沒有水平溢出。
